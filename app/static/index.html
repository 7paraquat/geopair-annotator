操作说明与快捷键
  • 多边形：逐点点击，点起点 / Enter / 闭合完成；Backspace 退一点，Escape 取消。
  • 道路中线：设路宽（完整像素宽度），沿道路逐点点击，再点“完成绘制”；生成后选择道路、点“编辑中线”可拖动中线点或修改当前侧路宽。
  • 三点矩形：先点一条边的两端，再点第三点确定垂直方向的宽度；可用于车辆等旋转目标。
  • 地块划分：圈定区域并完成绘制；画分界线，每条线点至少两点后完成绘制，可画多条；点回线的起点可闭合，开放线须接到外边界才能分开地块；再选“逐块分类”，选类别后点击每块，最后点“生成地块”并保存。
  • 点击哪侧就调整哪侧；同一轮廓必须在同侧闭合。移动本侧可整体拖动，重画本侧保持地物编号。
  • 选择后可拖动多边形顶点；图外部分自动裁剪，交叉和退化形状不能保存。
  • 局部放大：在原图移动定位，光学/SAR显示同一区域；放大区也可标注，倍数为原图显示比例的2/4/8倍。
  • 笔刷和橡皮擦作用于选中掩膜，只修改当前侧；涂改后转为像素掩膜。
  • 矩形和全图工具直接创建掩膜；类别未选时禁止保存。
  • ↑↓ 改变覆盖顺序；删除后才会从导出中去除该标注。
  • 打开影像自动申请编辑权；有人作业时只读。切图释放，断线90秒自动释放。
  • Ctrl+S 保存；Ctrl+Z 撤销；Ctrl+Shift+Z 重做。保存后导出光学、SAR 两份 TIFF 与同一类别表。
