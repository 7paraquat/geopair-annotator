# GeoPair Annotator v0.4.1

## 本次更新

- 在标注列表或影像上按 Ctrl/Shift 点击，可选择多个地物。普通点击恢复单选。
- 选择“移动本侧”后拖动，所选地物一起平移当前光学或 SAR 一侧；另一侧保持不变。一次撤销可恢复整组位置。
- 平移道路时保留中线和路宽；移动到图外的部分按原图尺寸裁剪。若任一地物完全离开影像，则取消本次移动。

## 更新方式

v0.4.0 启动时会检查 GitHub 正式 Release，自动下载并校验 v0.4.1。已打开标注页时，先保存当前修改，再点击“安装更新”。离线使用者可下载本版 ZIP 手动更新；更新保留 `workspace` 和外部数据集。
