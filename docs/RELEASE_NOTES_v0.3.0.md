# GeoPair Annotator v0.3.0

## 新功能

- 区域划分：先圈定一片区域，再画多条开放或闭合分界线。开放线连接外边界后可将区域切开；闭合线可圈出内部地块。逐块选择类别后生成互不重叠的掩膜，分界线像素归入相邻地块，不留下未标窄缝。
- 三点矩形：点第一条边的两端，再点第三点确定垂直宽度，快速框选旋转的车辆等目标。默认类别为车辆，生成后仍可修改类别和两侧轮廓。
- 区域划分期间可撤销最近一条已完成分界线。未完成分类时不能生成地块，未生成的划分不能保存或切换影像。

## 更新方法

使用 v0.2.0 的人员：先在网页点击“保存修改”，回到启动窗口，点击“选择新版 ZIP 更新工具”，选择 `GeoPairAnnotator-v0.3.0-windows-x64.zip`。程序会关闭、更新并重新打开。`workspace` 中的标注和类别、外部 `数据集` 文件夹均保留。

仍使用 v0.1.0 的人员：旧版没有更新按钮，请按 [v0.2.0 更新说明](RELEASE_NOTES_v0.2.0.md)中的手动覆盖方式操作，但改用本次 v0.3.0 ZIP。保留旧 `workspace`，不要覆盖或删除。

## 验证

已检查开放分界线与闭合分界线、三块不同类别的完整无重叠覆盖、三点矩形垂直边、标注保存，以及从 v0.2.0 到 v0.3.0 的隔离升级。发布包不含真实数据集和标注。
