# GeoPair Annotator v0.4.4

## 本次更新

- 标注网页新增“导出类别表”，下载包含稳定类别 ID、英文类别和中文类别的 CSV；自定义类别也会一并导出。
- CSV 使用 UTF-8 BOM，便于直接在 Excel 中打开。未标注（ID 0）和背景（ID 1）保留在表中，方便对照掩膜像素值。
- 已有标注和影像不变。更新前请保存当前网页中的修改。

## English

The annotation page can now export a UTF-8 CSV containing category IDs and English/Chinese names, including custom categories. Existing annotations and image files are unchanged.
