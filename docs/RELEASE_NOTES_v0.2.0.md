# GeoPair Annotator v0.2.0

## 本次更新

- 新增“道路中线”工具：输入道路完整像素宽度，沿道路逐点点击，完成后自动生成原尺寸掩膜。
- 新增“编辑中线”：光学和 SAR 可分别拖动中线点、调整路宽；同一个道路对象仍使用同一个标注 ID。
- 道路中线、路宽随标注一同保存，导出时分别生成光学和 SAR 掩膜。服务端会校验中线、宽度与掩膜一致性。
- 桌面启动窗口新增“选择新版 ZIP 更新工具”。从本版起，后续可用下载的新版 ZIP 在软件内更新；更新时保留 `workspace`，无需重发影像。

## 已分发旧版如何升级

旧版没有内置更新按钮，首次升级请按以下步骤。操作前先在标注网页点击“保存修改”，关闭旧程序；建议额外用旧程序导出一次标注 ZIP 备份。

1. 下载 `GeoPairAnnotator-v0.2.0-windows-x64.zip` 并完整解压。
2. 打开旧任务包中的 `GeoPairAnnotator` 文件夹。保留其中的 `workspace` 文件夹；旁边的 `数据集` 文件夹也保留原位。
3. 从新版解压出的 `GeoPairAnnotator` 文件夹复制程序文件到旧文件夹，遇到同名文件选择覆盖。**不要删除或覆盖旧 `workspace`。**
4. 双击旧文件夹中的 `GeoPairAnnotator.exe`。原数据集路径和已保存标注应继续可用。刷新打开的标注网页即可看到“道路中线”。

如果新版解压目录与旧目录不在同一位置，也可把旧 `workspace` 整个复制到新版 `GeoPairAnnotator` 文件夹中，再在新版目录启动。只选择其中一种方式，不要同时在两个工作区继续标注。

## 后续版本如何更新

在 v0.2.0 及以后版本的启动窗口点击“选择新版 ZIP 更新工具”，选择官方发布的完整 Windows ZIP。程序会核对版本、文件清单及 SHA256，确认后关闭旧程序、替换程序文件并重新打开。`workspace` 与外部 `数据集` 不参与替换；失败时尝试恢复旧程序文件。

更新包只应从项目的 GitHub Releases 获取。更新前仍需在网页保存当前修改；更新功能不会保存未提交的浏览器草稿。标注任务包里原有的影像无需重新下载。

## 验证

已用独立测试工作区验证道路中线的光学/SAR 掩膜逐像素导出、保存恢复、旧 ZIP 到新版的升级和 `workspace` 内容保持不变。未对所有 Windows 电脑环境逐一验证。
