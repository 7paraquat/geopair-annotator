# GeoPair Annotator v0.4.2

## 本次更新

- GitHub Release 附件下载遇到网络错误时，自动尝试仓库 `update-feed` 分支的 Git 对象备用通道。备用包必须与正式 Release 的版本、大小及 SHA256 一致，并通过 ZIP 内逐文件校验。
- 启动窗口显示在线更新失败的具体原因，便于区分版本查询、附件下载和备用通道错误。
- 标注数据、类别与外部影像不变。

## 首次升级

v0.4.0 和 v0.4.1 尚无备用通道。若其在线更新被网络阻断，请选择本地 v0.4.2 ZIP 更新一次；之后的正式版本可自动尝试备用通道。更新前先保存网页修改。
